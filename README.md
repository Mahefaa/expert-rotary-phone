# Expert Rotary Phone 📞

Ce dépôt contient le code source et la configuration CI/CD d'un projet web statique. Il a été réalisé dans le cadre d'un **Travail Pratique (TP) noté**.

Le projet illustre la mise en place d'un flux de travail automatisé (workflow) utilisant GitHub Actions pour le déploiement ou la validation d'une page HTML.

## 📋 Description

L'objectif de ce projet est de démontrer la maîtrise des concepts suivants :
* Gestion de version avec **Git**.
* Création d'une page web statique simple (`index.html`).
* Automatisation des tâches via **GitHub Actions** (CI/CD).

Le dépôt porte un nom généré aléatoirement ("expert-rotary-phone"), mais il constitue une base solide pour l'expérimentation DevOps.
